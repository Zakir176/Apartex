# Contributing — proposed additions

Thanks for wanting to contribute to Apartex! Below are suggested steps and a summary of expectations.

How to contribute
1. Fork the repository
2. Create a feature branch:
   `git checkout -b feat/your-feature`
3. Commit changes with meaningful messages
4. Push to your fork and open a pull request

Code style and testing
- Run linters and tests locally before opening a PR

Pull request process
- PRs should include a clear description, related issue (if any), and testing notes

Code of Conduct
- Consider adding a CODE_OF_CONDUCT.md to set community expectations
