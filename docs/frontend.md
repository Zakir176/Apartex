# Frontend — Developer Guide

Overview
- The frontend is in frontend/ and provides the web interface.

Run locally

```bash
cd frontend
npm install
# Create .env.local and set REACT_APP_API_BASE_URL or equivalent
npm start
```

Build for production

```bash
npm run build
```

Serve production build

```bash
npx serve -s build
```

Testing

```bash
npm test
```
